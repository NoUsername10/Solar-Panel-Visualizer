# Solar Panel Visualizer 0.2.5

Release date: 2026-11-05

This release restores the GUI setting labels in Home Assistant 2026.11 and adds a tested, manually reviewed draft-release workflow.

## Fixed

- Replaced removed `ha-formfield` wrappers with labels rendered by `ha-switch` across the editor and panel quick setup.
- Corrected strict TypeScript errors and added type checking to the release checks.

## Install

Update Solar Panel Visualizer from HACS, then reload the Home Assistant frontend if HACS asks you to.

No manual YAML changes are required. Existing card configurations continue to work.
